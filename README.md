# AI-администратор

Бот-администратор для малого бизнеса: отвечает клиентам в веб-чате и WhatsApp, называет цены из фактов компании, записывает на время и передаёт заявку владельцу.

- Весь код бота — в файле `worker.js` (Cloudflare Worker).
- Демо: https://ai-admin.azikonps4.workers.dev/ — витрина ниш, `/?c=barber` — барбершоп.
- Запись в расписание Altegio: бот берёт услуги, мастеров и свободное время из Altegio и сам создаёт запись.
  Проверка связи: `/altegio?key=<LEADS_KEY>`. Чат с записью: `/?c=alt`.
- Ключи и пароли в репозитории не хранятся. Они заданы в панели Cloudflare (Settings → Variables and Secrets).

## Как обновляется бот

1. Изменение попадает в ветку `main` этого репозитория.
2. Cloudflare сам запускает проверку `node test/smoke.mjs` (сценарии на заглушках, без сети).
3. Если проверка прошла, Cloudflare выкладывает новую версию. Если нет — на сайте остаётся прежняя.

Черновики живут в ветке `dev`: Cloudflare собирает для неё отдельный черновой адрес, рабочий сайт при этом не меняется.

Откатить версию: Cloudflare → Workers & Pages → `ai-admin` → Deployments → нужная версия → Rollback.
