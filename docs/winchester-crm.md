# Winchester: интеграция с Altegio — обещано заказчику, что есть, чего не хватает, архитектура

Зафиксировано 17.10.2026 со слов владельца. Источник правды о записях — журнал Altegio (CLAUDE.md §5.1).
Доступ: в Altegio Winchester создан отдельный сотрудник с ролью «просмотр» (для бота). Клиентская база — 18 891 клиент.

## 1. Что обещано заказчику

**Бот в WhatsApp (запись):**
1. Видит настоящий журнал: кто, к какому мастеру, на какое время записан.
2. Прежде чем сказать «записала», проверяет, что окно свободно; если занято — так и говорит и предлагает ближайшие свободные.
3. Делает настоящую запись в журнал Altegio.
4. Переносит **только записи, которые создал сам**, и только по просьбе клиента.
5. Отменяет записи только по просьбе клиента (и в оговорённых сценариях); чужие записи (сделанные администратором) — не трогает, передаёт администратору.
6. Отрабатывает все сценарии: запись, «что у меня записано», перенос, отмена, опоздание, «к любому мастеру», занятое время, нерабочий день, несколько услуг.

**Рассылки (раздел «Рассылки» нового пульта, ветка `pult-v2`):**
1. База клиентов берётся из Altegio автоматически, без Excel.
2. Умная сортировка кнопками: новые, повторные, потерянные (давно не были), постоянные, по мастеру, по сумме, по дате последнего визита.
3. Готовые сценарии: «вернуть потерянных», «поздравить», «акция дня», «напомнить о повторной стрижке через N недель».

**Пульт чатов:** вся информация из Altegio о клиенте рядом с перепиской.

## 3. Чего не хватает — по порядку

### Шаг A. Доступ (владелец, 15 минут) — без этого ничего не заработает
1. **Права роли «просмотр» в Altegio**: на снимке клиентской базы номера скрыты (`+7 707 XXX-X7-44`). Если API отдаёт так же,
   бот не найдёт записи клиента по номеру, а рассылки невозможны. В Altegio → Настройки → Права доступа → роль бота: включить
   **«Показывать номера телефонов клиентов»**, доступ к **журналу записей** и **клиентской базе** (чтение). Создавать/удалять — не нужно:
   бот записывает и отменяет через онлайн-запись.
2. Получить ключ: `/altegio/user?c=winchester` на черновике → логин и пароль **сотрудника-бота** → страница выдаст ключ →
   Cloudflare, Previews: Secret `ALTEGIO_USER_WINCHESTER`. Черновик видит новые секреты только после пересоздания ветки `dev`
   (как 17.10).
3. Онлайн-запись Altegio у Winchester должна быть включена (через неё бот записывает).

### Шаг B. Включить настоящую запись (код готов, нужна проверка вживую)
1. Пробная запись на `/altegio?c=winchester` (создаётся и сразу удаляется) — видно, что журнал показывает запись бота.
2. Прогнать сценарии из §1 в веб-чате `/?c=winchester` с режимом записи (запись на время за пределами рабочего дня мастера,
   «к любому», занятое окно, перенос, отмена).
3. Только с разрешения Кайрата: Text `ALTEGIO_DRY_WINCHESTER = 0`, `ALTEGIO_SELF_CANCEL_WINCHESTER = 1`.

### Шаг C. База клиентов из Altegio (новый код, ~2–3 дня)
- `services/integrations/altegio/clients-api.js`: чтение клиентов страницами по 200 (≈95 запросов на 18 891), только чтение.
- Фоновая задача ночью: загрузка порциями (лимиты Altegio и Worker), снимок в хранилище: телефон, имя, визиты, сумма, первый и
  последний визит, любимый мастер. Номера — только в хранилище, в журнал сервера — через `logSafe`.
- Сегменты в `services/broadcast/segments.js`: новые (1 визит), повторные (2+), постоянные (5+), потерянные (не было N дней),
  по мастеру, по сумме. Исключать «стоп» (`optout:`) и тех, кто записан на ближайшие дни.
- API для пульта: `GET /api/crm/segments?c=…` (кнопки с числами), `POST /api/bc/...` (как сейчас, но получатели — из сегмента).

### Шаг D. Пульт (`apps/pult`, делает друг; сервер — мы)
- Карточка клиента: визиты, сумма, любимый мастер, последняя и ближайшая запись — из снимка Altegio и журнала.
- Раздел «Рассылки»: кнопки сегментов с числами, выбор шаблона, пробная отправка себе, ход рассылки.
- Подключение к `/api/inbox/*` и раздача нового пульта сайтом.

## 4. Ограничения, о которых нужно сказать заказчику честно

1. **Meta ограничивает рассылки**: новый номер — до 250 разных получателей в сутки, предел растёт, если качество номера
   хорошее. 18 891 клиента за один день разослать **нельзя**; разумно — порциями, начиная с тех, кто был недавно.
   После блокировки 16.10 номер особенно чувствителен: первые 1–2 недели без массовых рассылок.
2. **Согласие**: писать первыми можно только одобренным шаблоном и тем, кто ожидает сообщений от барбершопа. Акции — шаблон
   категории «Маркетинг», в каждом — «напишите стоп». Иначе жалобы → жёлтое качество → блокировка.
3. Бот не трогает записи, созданные администратором, — это правило, а не недоработка.
4. Ни один пункт §1 пока **не проверен вживую** на журнале Winchester.
