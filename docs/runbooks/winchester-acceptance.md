## 3в. Живая проверка рассылки второго номера (финальное ТЗ рассылок, 02.11.2026)

Нужно: новая версия на адресе, где работает второй номер (тестовый стенд `ai-admin-test` с инстансом Green-API владельца или боевой
сайт — только после «выкладывай»). Клиентам ничего не уходит: тест — только на номер владельца, запуск выключен.

1. Пульт → «Рассылки» → «Автоматические» → «Номер для проверки» — свой номер.
2. «Рассылки» → «Создать рассылку» → Аудитория (например, «Пора на стрижку») → Сообщение (например, «Стрижка уже отросла?») →
   Предпросмотр → Проверка → Тест → «Отправить тест». Ожидается: на ваш WhatsApp со второго номера пришло «Добрый день, Айгерим! 👋🏻 …»
   (вымышленное имя для пробы), текст — как в предпросмотре.

   «Клиенты» → карточка → «Согласие на рекламу» → «Да, в переписке»); владелец ставит `GA_BROADCAST_WINCHESTER = 1` (Cloudflare →
