## 3. Живая проверка на двух разрешённых номерах

Кто нужен: **телефон второго номера** Winchester (WhatsApp с привязанным Green-API, у администратора) и **телефон Т** — разрешённый
тестовый номер «клиента» (свой номер владельца или Кайрата, с их согласия). Пульт открыт на телефоне администратора (`/app/`) и на
компьютере (программа для Windows или `/inbox`). Перед началом — `docs/runbooks/winchester-go-live.md`, шаг 5, весь зелёный.

Безопасный вариант до выкладки — те же шаги на отдельном тестовом Worker с тестовым инстансом и тестовым номером вместо рабочего
(`winchester-go-live.md`, раздел 6): рабочий вебхук и боевой сайт не трогаются.

## 4. Демонстрация Кайрату (10–15 минут)

Показывать на боевом сайте после живой проверки (раздел 3) или на снимках локального стенда (вымышленные клиенты; набор снимков —
`winchester-demo`, передаётся владельцу отдельно). Говорить только о том, что проверено; выключенное называть выключенным.

1. **(1 мин) Что это.** Один пульт для WhatsApp барбершопа на телефоне и компьютере; форма записи на сайте; напоминания клиентам —
   включаются по его слову.
2. **(3 мин) Чаты.** Очередь «Нужен ответ» с подписью номера; открыть чат, ответить, показать галочки; фото от клиента; ответ цитатой;
   «Взять себе» — видно, кто ведёт клиента.
3. **(2 мин) Карточка клиента.** Записи из Altegio (только чтение), «Свободное время», «Скопировать подтверждение». Записывать,
   переносить и отменять — по-прежнему в Altegio.
4. **(2 мин) Заявка с сайта.** Пройти форму на телефоне → «Заявка принята» → заявка в пульте и в Telegram → администратор записывает
   в Altegio → «Отправить клиенту и закрыть».
5. **(2 мин) Честность при сбоях.** Если WhatsApp не подтвердил отправку — пульт пишет «Не знаем, ушло ли», второй раз сам не
   отправит; двойное нажатие не дублирует сообщение.
6. **(2 мин) Напоминания.** Тексты (накануне, за 2 часа, просьба об отзыве), одобрение владельцем, «Проверить по журналу (без
   отправки)». Включаются только после его «отправляй».
7. **(1 мин) Что выключено и почему.** Бот на обоих номерах; рассылки со второго номера (риск блокировки); настоящая запись с сайта
   (сначала проверка в режиме заявок).
8. **(1–2 мин) Решения Кайрата** — раздел 5.

## 5. Что сделать вместе с Кайратом

1. **Второй номер:** чей номер; QR-подключение в кабинете Green-API (телефон с этим WhatsApp рядом); телефон всегда онлайн, из
   «Связанных устройств» не выходить.
2. **Основной номер `+7 700 505 05 03`:** остаётся в пульте (Wazzapo, вебхук на боевой адрес) или отключается от API и живёт только в
   телефоне (решение 30.10).
3. **Сотрудники:** кто работает в пульте; владелец выдаёт ключ сотрудника («Мои боты» → Winchester); каждый вписывает своё имя на
   устройстве; программа для Windows на компьютере ресепшена.
4. **Тексты напоминаний:** прочитать и одобрить (Рассылки → Сервисные); после этого — его «отправляй» → `REMIND_GA_WINCHESTER = 1`.
5. **Запись с сайта:** неделя в режиме заявок → решение о настоящей записи (после исправления P1 из раздела 2).
6. **Telegram:** кому приходят заявки и сигналы (`TG_CHAT_WINCHESTER`).
7. **Приёмка:** пройти раздел 3 вместе, заполнить «Результат», отметить «принято» или список замечаний.
