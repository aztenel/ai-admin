# ТЗ Winchester v5 (27.11.2026, от Кайрата через владельца)

Исходник — Word-файл владельца с картинками (в репозиторий не кладём: там данные владельца ИП).

## Сайт winchester.kz (`apps/winchester-site`)
1. Первый экран: вместо картинки — лёгкое видео из Instagram Winchester (вертикальное для телефона, горизонтальное для компьютера; 1–2 МБ, без звука, по кругу, постер до загрузки; при медленной сети, экономии трафика и «уменьшить движение» — только картинка). Нужны файлы видео от владельца.
2. Номер +7 777 114 86 59 (Pushon, пульт) рядом с +7 700 505 05 03 везде, в том же стиле; 0503 остаётся. Кнопка «Написать в WhatsApp» — на 777.
3. Стоковые фото → карусель реальных работ (свайп, стрелки, точки по центру внизу). Нужны фото работ.
4. После цен — блок команды с общим студийным фото (включая администраторов). Нужно фото.
5. Подвал: убрать ИИН и телефон владельца ИП и лишние данные (решение владельца 27.11.2026).
Делаем сначала демо: проверка скорости, тесты, дизайн; на hoster.kz загружает владелец архивом.

## Meta и пульт
1. 10–15 новых рекламных шаблонов без «ИИ-текста» — `docs/winchester-templates-v5.md` (14 шт.). Кнопку «Отписаться» в шаблоны не добавляем (владелец создаёт шаблоны сам, Meta не требует).
2. Предел 250 переписок → 2000: подтверждение компании в Meta или 300 начатых переписок за 30 дней при высоком качестве (сервисные шаблоны тоже считаются).
3. Официальная галочка WhatsApp — пробовать после подтверждения компании.
4. «Отписаться» в сервисных шаблонах (автоматически добавлял Pushon): нажимают случайно (бонусы 2 из 80, напоминание 2 из 21, благодарность 1 из 93, подтверждение 1 из 91; всего 7 в списке Pushon). Новые сервисные шаблоны — без этой кнопки. На рекламе — 3 настоящие отписки из 220 (это нормально).
