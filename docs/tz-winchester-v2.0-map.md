## Green-API: что умеет на самом деле (по документации)

- Статусы исходящих — вебхук `outgoingMessageStatus`: `sent`, `delivered`, `read`, `failed` (с `description`), `noAccount`,
  `notInGroup`, `suspended` (`yellowCard` — устаревшее). Порядок доставки вебхуков не обещан; `delivered` бывает пропущен
  (чат открыт у получателя — сразу `read`), `read` — тоже (отчёты о прочтении выключены). Нужны настройки
  `outgoingWebhook = yes` (статусы) и `outgoingMessageWebhook = yes` (сообщения с телефона), для сообщений через API —
  `outgoingAPIMessageWebhook = yes`.
- Сообщения с телефона и через API — вебхуки `outgoingMessageReceived` / `outgoingAPIMessageReceived`; статусы приходят и на
  сообщения с телефона (`sendByApi: false`).
- Журналы `lastOutgoingMessages` / `lastIncomingMessages` (по умолчанию 1440 минут) — со статусом `statusMessage` и `sendByApi`;
  сообщение появляется там до 2 минут; не чаще 1 запроса в секунду.
- Файлы: `fileMessageData { downloadUrl, caption, fileName, mimeType, jpegThumbnail }`, голосовое — `audioMessage` (`audio/ogg`);
  срок ссылки не указан («ограничен WhatsApp»); новую ссылку даёт `downloadFile { chatId, idMessage }` (500 — файла у WhatsApp
  уже нет).
- Правка и удаление — `editedMessage` / `deletedMessage` (настройки `editedMessageWebhook`, `deletedMessageWebhook`).
- Реакции — `reactionMessage`; цитата — `quotedMessage`.
- Повтор вебхука: Green-API ждёт ответ 180 с, без 200 повторяет каждую минуту, «гарантированно в течение 24 часов».
- Отметить прочитанным — `readChat`.
- **Бесплатный тариф Developer — только 3 чата в месяц** и пределы на журналы (1000 в месяц) и `downloadFile` (500).
  Тариф номера Winchester надо проверить в кабинете Green-API.
- Защита от блокировки (их советы): не больше 200 получателей в сутки, рассылки — 1 сообщение в минуту, не больше 8 часов в
  день и 3 дней подряд, только тем, у кого номер сохранён.

## Конфликты и риски

1. **Рассылка по базе Altegio не требует согласия** (и ждёт 14 дней, а не 30) — противоречит решению владельца; исправляется
   в P1 (кампании), до этого реальные рассылки выключены.
2. **Основной номер отключают от API** — в пульте останется только второй номер; ТЗ предполагает оба.
3. **Нет отдельных учётных записей сотрудников** — «Назначено мне» можно сделать только по имени сотрудника на устройстве
   (не защита доступа: права — по-прежнему ключ компании).
4. **У черновиков нет фоновой задачи** (Cloudflare не запускает cron у Worker Previews): напоминания и сверки в `dev` — только
   кнопкой; push уходит из вебхука, ему cron не нужен.
5. **История чата в KV живёт 7 дней** после последнего сообщения — «Закрытые» и журнал старше 7 дней не сохраняются (в D1 есть
   таблица `messages`, пока только у черновика).
6. **Тариф Green-API** — на бесплатном тарифе пульт увидит только 3 чата в месяц.
7. **Локализация персональных данных РК** — до боевого импорта базы нужна отдельная проверка закона (данные в Cloudflare).
8. **В Telegram уходит ссылка на файл клиента** (`handleWAMedia`) — закрытая ссылка Green-API в чате; убрать.
