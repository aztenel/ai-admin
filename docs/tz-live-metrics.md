# Задание: живые метрики в пульте (запрос владельца 26.11.2026)

Статус: **не сделано**, только записано. Делать после решения владельца.

## Что хочет владелец

Отдельный раздел пульта «Метрики» с живыми цифрами по каждому отправленному шаблону:

- вид шаблона (реклама / сервисное) и сам шаблон (название и текст);
- отправлено, доставлено, прочитано, ответили — числа и доли в процентах;
- переходы на сайт и другие нажатия (кнопки шаблона, ссылки);
- **сколько настоящих записей** — главная цифра.

## Как считать «записался» (идея владельца)

Реклама ушла клиенту → потом этому же номеру ушло сервисное «Запись подтверждена» (S01)
по записи, **созданной после** рекламы (`create_date` из журнала Altegio) в пределах окна (14 дней).

- Один номер = одна запись в счёт рассылки (без двойного счёта; повторная доставка, два шаблона,
  пересечение рассылок — считаем один раз, к последней рекламе до записи).
- Подтверждение S01 уже защищено от дублей (`rms:`, D1 `send_claims` `a-s01-<запись>-…`) — опора надёжная.
- Записи, сделанные администратором, через сайт и бота, считаются одинаково (журнал — правда), источник показываем отдельно.
- Это совпадение по времени, а не доказательство — подписывать в пульте так.

## Уточнение владельца 26.11.2026: записываются не только по кнопке

Сайт напрямую, звонок администратору, другой номер (+7 700 505 05 03), пришёл сам и записался на месте,
написал в том же чате «запишите». Поэтому кнопка и переход — не мера записей.

Решение: все пути сходятся в журнале Altegio. Считаем **любую новую запись этого номера** в журнале,
созданную после рекламы (окно 14 дней), без разницы, откуда, и показываем источник отдельно
(бот / сайт / администратор — как в `booking-card.js`). Подтверждение S01 — только запасная опора.

Где не увидим: записали на другой номер (жена, друг), пришёл без записи и номер в Altegio не внесли.

Чтобы отличить «пришёл из-за рекламы» от «пришёл бы и так» — **контрольная группа**: часть сегмента
(например 10%) рекламу не получает, сравниваем долю записей у получивших и у контрольной. Без неё
«записались после» всегда будет выше настоящего эффекта (постоянные клиенты записываются и без рекламы).

## Что уже есть

- События доставки в D1 `events` (`msg_*`, `campaign_id`), кому ушло — `bcs:<клиент>:<id>`.
- Отметки сервисных `rms:`/`rmok:`, `send_claims`.

## Чего нет

1. Раздела «Метрики» сводно по всем шаблонам (сейчас итоги — внутри одной рассылки).
2. Связи «реклама → подтверждение S01 по новой записи» (сейчас «записались» — по снимку базы).
3. **Нажатий и переходов на сайт нет совсем.** Нужно: ссылка через наш адрес-счётчик
   (`/r/<код>` → winchester.kz), код — на рассылку и получателя. У шаблонов Meta с постоянной ссылкой
   в кнопке переход по получателю не узнать — нужна кнопка со ссылкой с подстановкой
   (шаблон переодобрять в Meta) или ссылка в тексте. Нажатия быстрых кнопок (не ссылок) приходят
   ответом клиента — их можно считать по вебхуку Pushon (формат не проверен, см. аудит, «Отписаться»).
4. Записи с сайта по ссылке из рассылки: метка в адресе (`?r=<код>`) → форма записи передаёт её в заявку.

## Концепт 26.11.2026

Страница-концепт (вид раздела, 14 разобранных случаев, контрольная группа, правила «чтобы не сломать»):
https://claude.ai/artifact/P4FdEPpxXEDkJQhYXiwbEg (частная, у владельца).

Правила, которые закрепить тестами при реализации:
1. Раздел только читает: ничего не отправляет и не пишет в Altegio.
2. Запись — только из журнала Altegio; засчитывается, если реклама дошла, `create_date` записи позже отправки и не позже окна (14 дней).
3. Один номер — одна запись; две рекламы — запись идёт последней перед записью; перенос — та же запись.
4. Не дошло — строка «не получили, но записались», в успех не идёт.
5. Итог закрепляется после окна; сбой чтения журнала — «не прочитано, цифры от …», не ноль.
6. Источник: сайт (пометка записи), ответ в чате рассылки (сообщение клиента до записи), администратор (звонок, 0503, на месте — не различаем), «похоже, пришёл сам» (создана почти в момент визита — догадка).
7. Контрольная группа ~10% случайно; меньше ~50 человек — «мало людей для сравнения».
8. Не видим: запись на чужой номер, визит без номера — «записались» это нижняя граница.
