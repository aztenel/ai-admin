# Пульт Winchester v3 — дизайн-система и экраны

Единый источник для Figma (`https://www.figma.com/design/Yxg9LPwnDXjygoYAzpTdI5`) и кода (`apps/pult`). ТЗ — «Winchester: единое
корректирующее ТЗ v3.0» (31.10.2026). При расхождении Figma и кода правим оба и этот файл.

## 1. Принципы

1. **Рабочий инструмент барбершопа, а не админка разработчика.** За 5 секунд видно: кто ждёт ответа, что с записями, что уйдёт само.
2. **Фирменный, но тихий.** Winchester — бордовый, кремовый, латунь. Цвет бренда — в полотне, пузырях, выбранном и главном действии.
   Иерархию строят размер, вес и отступы. Красный — только ошибки и «ждёт ответа».
3. **Один экран — одна задача, одно главное действие.** Второстепенное — в меню «⋯» или в деталях по нажатию.
4. **Честные состояния.** «Тестовая версия», «Демо», «Запуск выключен», «Статус неизвестен» — видно и понятно, без технических слов.
5. **Текст для администратора.** Без слов «вебхук», «KV», «D1», «Meta-шаблон», «слот», `{{1}}`, `S03`, длинных тире-разделителей
   и декоративных кавычек.

## 2. Темы и цвета

Две оси: **оформление** (Winchester / Нейтральное) и **режим** (Как в системе / Светлое / Тёмное). У Winchester по умолчанию
оформление Winchester; у других компаний — нейтральное (бренд — по компании, `brand` из `/api/inbox/me`).
Токены — CSS-переменные `apps/pult/src/index.css` (`[data-brand="winchester"]` × `[data-theme="light|dark"]`).

Фирменные исходники (сайт winchester.kz): obsidian `#210F0F`, walnut `#321616`, burgundy `#5A1E1E`, ivory `#F3EBDD`,
brass `#C9A66B`, taupe `#B7AA98`, ink `#5F5448`, night `#170A0A`.

`accent` ≥ 7:1 (Winchester светлая: `#FBF7F0` на `#5A1E1E` ≈ 11:1); тёмный текст на латуни (`#210F0F` на `#C9A66B`) ≈ 8:1.

**Фон переписки** (Настройки → Оформление): `Однотонный` (canvas), `Узор` (едва заметные латунные точки 1px, шаг 22px, 6%),
`Кожа` (тёплый градиент walnut→obsidian, только в тёмной). Фото на фоне не используем — мешают читать.

## 3. Шрифты и размеры

- Основной шрифт — системный (`-apple-system`, SF Pro, Roboto): поддерживает казахские буквы, ничего не грузит.
- Фирменный акцент Winchester — **Oswald 600** только в больших заголовках экранов (34/36) и в логотипной строке. Файл шрифта
  кириллица — с сайта (`apps/winchester-site/assets/fonts/oswald-cyrillic-600-normal.woff2`). Капс не используем.
- Шкала: 34/40 заголовок экрана · 22/28 заголовок листа · 17/22 строка, имя · 15/20 основной текст, пузырь · 13/18 подпись ·
  12/16 мелкая отметка (время). Меньше 12 не бывает.
- Цифры — табличные (`tnum`) в счётчиках и времени.

## 4. Сетка и отступы

- Шаг 4/8: 4, 8, 12, 16, 20, 24, 32, 40. Боковое поле телефона — 16. Касание — не меньше 44×44.
- Радиусы: 8 (поля, чипы малые), 12 (кнопки, тосты), 16 (карточки, листы), 20 (пузыри), 999 (чипы, аватары).
- Телефон 390×844: нижняя панель 5 разделов + safe area; лист снизу на всю ширину; главное действие шага — снизу, не закрывает поле ввода.
- Компьютер 1280×800: левая полоса разделов 76; чаты — список 360 · переписка · карточка клиента 340 (по кнопке).

## 5. Компоненты и состояния

Состояния у каждого: обычное, нажатие, наведение (компьютер), фокус (кольцо 2px `ring`), загрузка, недоступно, ошибка, успех.

| Компонент | Суть |
|---|---|
| Кнопка | `primary` (accent), `secondary` (surface-2), `ghost`, `danger`; 44/36 высота; загрузка — спиннер вместо иконки, текст «Отправляю…» |
| Чип / фильтр | капсула 32–36, счётчик справа, выбранный — `selected` |
| Вкладки раздела | сегменты в капсуле; выбранная — `surface` с тенью; у Winchester — тонкая латунная линия снизу |
| Строка чата | аватар 48, имя 17/600, время 13, одна строка текста, вторая — причина («Просит перенести») красным и номер (Второй WhatsApp) |
| Пузырь | клиент слева `bubble-in`; сотрудник справа `bubble-op`; авто (напоминание, рассылка) справа `bubble-auto` с подписью «Напоминание» |
| Галочки | 1 серая — отправлено, 2 серые — доставлено, 2 акцентные — прочитано, «!» красный — не дошло (по нажатию причина), часы — ждёт |
| Плеер голосового | кнопка 40, полоса, время, скорость 1× / 1,5× / 2× |
| Карточка клиента | имя, номер, «Кто ведёт», ближайшая запись, история сообщений; длинное — по нажатию |
| Нижний лист | ручка, заголовок 22, одно главное действие снизу |
| Тост | один на экране, снизу над панелью; новый заменяет старый; ошибка — с кнопкой «Повторить» или «Закрыть» |
| Пустое состояние | значок 40, одна строка, одно действие |
| Скелетон | серые плашки формы строк, без мигания при обновлении |
| Пузырь-предпросмотр WhatsApp | зелёная шапка «WhatsApp», пузырь как у клиента, только готовый текст |
| Редактор текста | поле + чипы вставки «Имя», «Мастер», «Услуга», «Дней после визита», «Ссылка на запись» |
| День календаря | число, точки: сервисные (латунь), реклама (бордовый), сегодня — кольцо |
| Метка режима | `Тестовая версия` (dev), `Демо` (демо) — капсула в шапке раздела |

## 6. Движение

140–220 мс, `cubic-bezier(.2,.7,.2,1)`; только `transform` и `opacity`. Переход экранов — сдвиг 16px + прозрачность. Лист — снизу.
Тост — появление снизу 8px. Новое сообщение — появление одного пузыря. Тема — без мигания (переменные меняются сразу).
`prefers-reduced-motion` — без сдвигов, только мгновенная смена.

## 7. Разделы и экраны

Навигация: телефон — 5 нижних разделов **Чаты · Заявки · Рассылки · Клиенты · Настройки**; компьютер — левая полоса тех же 5.

### Чаты
- Шапка: «Чаты», под ней компания и метка режима; справа выбор номера («Все номера / Основной / Второй»). Поиск виден всегда.
- Фильтры одной строкой с прокруткой: Нужен ответ · Записи · Ответы · Мои · Все · Готово (счётчики у первых трёх).
- Переписка: имя, «Второй WhatsApp» под ним; полоса действия только когда нужно: «Ждёт ответа 5 мин» + «Взять себе».
  Внизу: быстрые ответы (молния), поле, отправка; над полем — «Ответ со второго номера».
- Карточка клиента — по нажатию на имя (телефон: отдельный экран; компьютер: правая колонка).

### Рассылки
- Вкладки: **Маркетинг · Сервисные · Календарь**.
- Маркетинг: карточка канала «Второй WhatsApp · На связи · Запуск рассылок выключен» + «Создать рассылку»; подвкладки
  **Рассылки · Шаблоны · Журнал**.
- Мастер (Green-API): Кому → Сообщение → Проверка → Когда → Итог. Итог: «Сохранить черновик», «Одобрить» (владелец),
  «Запустить» — недоступно, пока владелец не включит запуск рассылок со второго номера (объяснение одной строкой).
- Шаблоны: счётчики «28 шаблонов · Одобрено N · На проверке N», поиск, фильтр (Все / Готовы / На проверке), категории
  (Приглашения, Давно не были, Свободное время, Постоянные клиенты, Услуги, Поводы, Персональные). Карточка: название, для кого,
  статус. По нажатию — лист: пузырь WhatsApp с примером клиента ↔ редактор, RU/KZ, «Что проверить перед отправкой», действия
  Изменить · Дублировать · Одобрить · Использовать.
- Сервисные: категории Запись · Напоминания · Изменения · Опоздания и неявки · После визита · Ошибки и задачи; у сценария:
  включён ли, когда уходит, текст, пример, очередь.
- Календарь: месяц и следующий месяц; в дне — точки сервисных и рекламы; по нажатию — список дня с числами и причинами.

### Клиенты
- Шапка: «Клиенты», одно главное действие «Добавить», меню «⋯»: Импорт из файла. Поиск, сегменты, итог «N клиентов · обновлено …».
  Проверки Altegio и синхронизация — в Настройки → Диагностика.

### Настройки
- Компания · Номера и каналы · Сотрудники · Оформление · Уведомления · Диагностика (только владелец).
- Номера и каналы: «Второй WhatsApp: На связи», «Основной WhatsApp: не подключён к пульту» (по реальным данным), «Запись с сайта:
  проверка без записи, заявки уходят администратору» (по настройке сервера).

## 8. Текст (кратко; полный словарь — `copy.md`)

- Короткие глаголы на кнопках: «Создать рассылку», «Сохранить», «Одобрить», «Взять себе», «Готово».
- Разделители: точка, двоеточие, перенос строки, «·» только в мета-строке. Длинное тире — только когда без него фраза неверна.
- Кавычки-ёлочки — только для названий в тексте, не для украшения.
- Пустые состояния: одна строка о том, что будет («Новых заявок нет»), без истории системы.
