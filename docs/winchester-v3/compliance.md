## Ограничения Figma (честно)

- Тариф Starter: **3 страницы** (вместо 7 по ТЗ) — «Основа», «Бренд», «Тексты» и «Сверка» сведены: основа и бренд — на странице 1,
  тексты и сверка — в этом репозитории (`copy.md`, `compliance.md`, `templates.md`).
- **1 режим переменных** на набор: 4 темы — 4 набора «Цвет · Winchester светлая / тёмная / Нейтральная светлая / тёмная» с
  одинаковыми именами `color/*` (имена = переменные CSS пульта).
- **Предел вызовов Figma MCP** на тарифе Starter исчерпан 31.10.2026 после 8 экранов телефона. Не сделано в Figma: экраны
  компьютера 1280×800, тёмные варианты экранов. Две тёмные копии («Телефон · тёмная · Чаты», «… Переписка», node `18-512`,
  `18-632`) перекрашены только снаружи: внутри экземпляров компонентов остались светлые цвета — их нужно удалить или пересобрать,
  когда предел обновится или тариф будет Professional.
