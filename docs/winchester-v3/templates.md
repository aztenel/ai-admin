# 28 рекламных шаблонов: состояние (ТЗ v3.0)

Собрано из кода (`src/services/broadcast/library.js`, подстановка `src/services/broadcast/render.js`) 31.10.2026.
Пример — на вымышленном клиенте: Самат, мастер Тони, 40 дней после визита, ссылка https://winchester.kz.

- «Готов, ждёт одобрения владельца» — текст без пропусков; уходит только после одобрения владельцем в пульте
  (Рассылки → Маркетинг → Шаблоны). Одобрение — решение о тексте, не отправка.
- «Нужны данные» — в тексте есть [скобки] (свободное время, условия акции, дата и т. п.): пока их не вписать, одобрить нельзя.
- Казахский текст у всех 28 — черновик: носитель языка его не проверял (`kkChecked: false`).
- С основного номера реклама уходит только шаблоном, одобренным Meta. Со второго номера запуск рассылок выключен в коде
  (`gaNoBroadcast`), можно только черновик и одобрение.
