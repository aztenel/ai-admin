# Словарь текстов пульта (ТЗ v3.0)

Правила — `design.md` §8. Здесь — что было и что стало в главных местах. Код — `apps/pult/src`, тексты сервера —
`src/controllers/broadcast.js`, `src/services/reminders/info.js`. При правке текста меняйте и эту таблицу.

Общие правила, по которым правили:

- Нет слов разработчика: вебхук, KV, D1, Meta-шаблон, слот, `{{1}}`, номера сценариев S01–S18 и тем M01–M28.
- Нет длинного тире как разделителя: вместо «А — Б» точка, двоеточие или «, поэтому».
- Кавычки-ёлочки — только для названий («Пора на стрижку», «стоп»), не для украшения.
- «Номер бота» → «Второй WhatsApp» (у Winchester бот на втором номере выключен, номер шлёт напоминания и отвечает людьми).
- Одна мысль — одно предложение. Пустое состояние — что будет, а не история системы.
