## Проект
- `worker.js` — весь бот: один Cloudflare Worker (веб-чат, WhatsApp Cloud API, Green-API, автотест `/selftest`, `/diag`, `/leads`, `/privacy`).
- `test/smoke.mjs` — сценарии на заглушках (KV, Gemini, Telegram, Meta подменены). Запуск: `npm test`.
- `wrangler.jsonc` — конфигурация заливки. `keep_vars: true` обязателен: переменные и секреты заданы в панели Cloudflare.

## Altegio
- Используется публичный API онлайн-записи (`api.alteg.io/api/v1/book_*`): нужен только ключ разработчика (секрет `ALTEGIO_PARTNER` в Cloudflare) и номер локации клиента.
- Локация клиента: `altegio.location` в его блоке `CLIENTS` или переменная `ALTEGIO_LOC_<ID>`. Тестовый клиент `alt` скрыт с витрины.
- Итог записи, отмены и переноса клиенту сообщает код (`altSay`) по ответу Altegio, а не текст ИИ. ИИ только ставит служебные строки `[ЗАЯВКА]` и `[ОТМЕНА]`.
- Активные записи чата — в `profile.bookings`. Перенос = `[ОТМЕНА]` + `[ЗАЯВКА]` в одном ответе: сначала создаётся новая запись, потом удаляется старая.
- Если Altegio не принял запись, бот не теряет клиента: создаёт обычную заявку администратору с пометкой.
- Лимиты автоматических записей: 4 на чат, 5 в сутки на телефон и на IP, 60 в сутки на локацию; сверх лимита — заявка администратору.
- `/altegio?key=<LEADS_KEY>[&loc=<номер>]` — что бот видит в Altegio. Кнопка «Пробная запись» создаёт запись и сразу удаляет её.
- Вживую с настоящим Altegio проверяй после каждого изменения этой части: страница `/altegio` и чат `/?c=alt`.

## Правила
- Ветка `main` = боевой сайт: Cloudflare Workers Builds выкладывает каждый коммит в `main` (сначала `node test/smoke.mjs`, потом `npx wrangler deploy`).
- Сборка черновых веток в Cloudflare (`npx wrangler preview`) пока падает, причина не выяснена: журнал сборки виден только в панели Cloudflare.
- Перед `main`: `npm test` и сравнение со старой версией для клиентов без Altegio. После выкладки — живой автотест: `/api/selftest?key=<LEADS_KEY>&i=<номер>`.
- Результат сборки виден без панели: `gh api repos/aztenel/ai-admin/commits/<sha>/check-runs`.
- Никаких ключей, токенов и паролей в репозитории и в чате.
- После выкладки проверяй вживую: `/`, `/?c=barber`, `/privacy` на https://ai-admin.azikonps4.workers.dev.
- Не обещай владельцу и его клиентам то, что не проверено вживую.
