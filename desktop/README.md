# Пульт для Windows

Программа «Пульт» — окно с пультом чатов AI-администратора. Внутри тот же пульт, что на сайте (`/inbox`), поэтому всё новое в пульте сразу появляется и в программе. Своё у программы:

- значок у часов (в трее): крестик не закрывает программу, а прячет окно — уведомления продолжают приходить;
- уведомления Windows, когда клиент ждёт ответа, и мигающий значок на панели задач;
- запуск вместе с Windows (галочка в меню значка у часов);
- одна копия программы: повторный запуск открывает уже открытое окно;
- ссылки на WhatsApp, карты и другие сайты открываются в браузере; на страницах сайта вне пульта (рассылки, заявки) — кнопка «← Пульт».

## Как установить

1. Откройте https://github.com/aztenel/ai-admin/releases и скачайте файл `AI-admin.Pult_…_x64-setup.exe` из самой новой сборки.
2. Запустите его. Windows может показать «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Так бывает, пока у программы нет платной цифровой подписи.
3. Откроется пульт. Войдите ключом один раз — программа запомнит вход.

Меню значка у часов: «Открыть пульт», «Запускать вместе с Windows», «Сайт: рабочий / черновик (для проверки)», «Выйти».

## Для разработки

- Исходники: `src-tauri/` (Rust, Tauri 2). Своей страницы нет: окно открывает `https://ai-admin.azikonps4.workers.dev/inbox` (или черновик, если выбран в меню).
- Сборка — только на GitHub (`.github/workflows/desktop.yml`, Windows): при изменении папки `desktop/` в ветках `dev` и `main`. Установщики — в Releases (из `dev` — «пробная сборка»).
- Пробный запуск в той же сборке: программа открывает `/demo` черновика с `PULT_SELFTEST=1` (на странице — плашка «TAURI OK · notification OK …»), снимок экрана — в ветке `desktop-shots`.
- Уведомления вызывает сам пульт (`pult/app.js`, `noteCheck`/`notify`): в программе — через `window.__TAURI__.notification`, в браузере — через `Notification`.
