# 02. SFON (Smartfon System) — бизнес-процессы

Дата: 05.11.2026. Подробности и все источники — `evidence/sfon.md`.

## 0. Чем и как исследовано

- **Доступа к аккаунту Prime Mobile нет**: владелец его не передавал. Вход, регистрация, подбор паролей, вызовы эндпоинтов с данными и любые изменяющие запросы **не делались**.
- Использовано: публичный сайт sfon.kz, публичная спецификация Open API (`https://open-api.sfon.kz/open-api/v3/api-docs`, OpenAPI 3.0.1, получена целиком), публичные статические JS-файлы фронтенда web.sfon.kz (строки интерфейса и пути внутреннего API — без входа), поиск (Instagram @smartfon.system, 2ГИС, YouTube).
- В публичном JS фронтенда зашиты учётные данные OAuth-клиента веб-приложения. Мы их **не используем и не воспроизводим**; SFON стоит сообщить об этом (это их риск, не наш).
- Уровни доказательств: **[API]** — документация Open API; **[Сайт]** — маркетинговый текст; **[Интерфейс]** — строки и маршруты публичного фронтенда (сильное указание, но вживую не проверено); **[Поиск]**.

## 1. Продукт в целом

- Smartfon System, веб-приложение SmartfonNext (Angular), витрина SFS Store (shop.sfon.kz), Астана; обкатан в сети Kop Kop Store (3 филиала) [Сайт].
- Два модуля: **«Электроника»** — учёт поштучно по IMEI (`systemType=SFON`) и **«Аксессуары»** — учёт количеством (`ACCS`) [Сайт, Интерфейс].
- Тарифы [Сайт]: Базовый — 21 000 (Электроника) / 11 000 (Аксессуары); Профи — 35 000 / 19 000; до скидки 35/19/50/27 тыс. Во всех — 2 магазина, без ограничения пользователей, 14 дней бесплатно. Период и валюта не указаны (вероятно ₸/мес — **не подтверждено**).
- Это важный ориентир цены для Prime Mobile OS: рынок уже платит **≈21–35 тыс. ₸ в месяц** за точку уровня SFON.

## 3. Что это значит для Prime Mobile OS

1. **Минимальный паритет с SFON** (без него Prime Mobile не перейдёт): поштучный учёт по IMEI с проверкой повторов; мастер приёмки партии со сканом и себестоимостью; продажа сканом; полный и частичный возврат по чеку; Trade-In в зачёт; перемещения с подтверждением получателем; долги клиентов и поставщикам; кассы и безналичные счета с комиссией; гарантийный талон по закону РК и чек в PDF с публичной ссылкой; роли владелец/админ/продавец с привязкой к магазину; журнал действий; отчёты прибыли и склада в себестоимости; выгрузка в Excel; витрина/наличие для сайта.
2. **Где можно обойти SFON:** IMEI2 и серийный номер отдельными полями; импорт из Excel (у SFON не подтверждён); полноценный API записи и вебхуки; фискализация через ОФД-провайдера; Kaspi (магазин, оплата, рассрочка — при официальном доступе); казахский интерфейс; мобильное приложение со сканером.
3. **Перенос данных из SFON** через Open API **невозможен целиком**: в нём нет IMEI, себестоимости, клиентов, долгов и истории. Остаётся выгрузка Excel из интерфейса SFON (её состав нужно увидеть в аккаунте) плюс инвентаризация сканом. План — в `07-development-roadmap.md`.

## 4. Пробелы

Без аккаунта не проверены: реальный состав выгрузок Excel (есть ли IMEI и себестоимость), работа скидок, отчёт по гарантийным случаям, лимиты Open API, реальная работа ролей. **Чтобы закрыть пробелы, нужен доступ «только чтение» от владельца Prime Mobile** (или созвон с показом экрана) и тестовая выгрузка каждого отчёта.
