# Новый пульт чатов (заготовка, фаза 4 `REFACTORING.md`)

Отдельное приложение пульта: Vite + React 19 + Tailwind CSS v4 + shadcn/ui. Работающий пульт по-прежнему в `pult/` → `pult.gen.js`; эта папка на него и на бота не влияет.

**Состояние:** собирается (`tsc` и `vite build` без ошибок), проверочный экран `src/App.tsx` открыт в браузере на вымышленных данных (`src/demo/data.ts`). К API бота (`/api/inbox/*`) **не подключено**, на сайт **не выкладывается**.

## Вид

Раскладка и цвета — по образцам с Dribbble (только как ориентир, не копия):
[D5 «Schedulo»](https://dribbble.com/shots/27083278) — чаты, [D15 «Barbara»](https://dribbble.com/shots/27600149) — цвета, меню, «Записи».
Ярко-синий акцент, светло-серое полотно, белые скруглённые карточки, шрифт Inter (`@fontsource-variable/inter`, раздаётся вместе с пультом). Токены — `src/index.css`.

- **Меню** (`src/App.tsx`): разделы «Основное / Маркетинг / Управление», счётчики в «таблетках», выбранный пункт — голубая подложка. Сверху — поиск-«таблетка» (Ctrl+K) и кнопка «Новая запись».
- **Чаты** (`src/screens/Chats.tsx`): одна белая карточка — список (вкладки «Ждут / Бот / Все», поиск, цветные аватары) | переписка (клиент — серый пузырь, бот — тёмный, администратор — синий; «Забрать чат», «Готово») | клиент: телефон, канал, визиты, полоска дней, свободное время, «Записать», записи, заметка. Вид «Доска» — переключатель над списком. На телефоне: список → чат → кнопка «i» открывает клиента.
- **Записи** (`src/screens/Bookings.tsx`): цифры дня, записи по часам с цветной полоской статуса, выручка по месяцам, «Выполнено за день», откуда записи, недавние клиенты; «Сегодня / Завтра».
- **Клиенты**, **Рассылки**, **Бот** — белые карточки в том же стиле.

## Запуск

```bash
cd apps/pult && npm install && npm run dev
```

Сборка: `npm run build` (папка `dist/`, в git не попадает).

Код компонентов — как пришёл из 21st.dev, кроме доски. В выдаче не хватало вспомогательных файлов, их дописали мы (помечены комментарием в начале файла):
`animated-sidebar-utils/ease.ts`, `animated-sidebar-utils/shared-layout-bg.tsx`, `chat-utils/use-interruption.ts`, `chat-utils/compose-refs.ts`.

Правки в `kanban-board.tsx` (описаны в начале файла): анимации из `motion/react` вместо отдельного `framer-motion`; русские надписи; `onTaskOpen` — нажатие без сдвига открывает карточку, перетаскивание начинается после сдвига на 5 px; место для карточки берётся там, где её отпустили; `onChange` вызывается вне обновления состояния (в оригинале React ругался, когда родитель менял своё состояние); `addLabel = null` прячет кнопку «добавить».

Базовые детали shadcn/ui: `button`, `input`, `textarea`, `input-group`, `avatar` — из выдачи 21st.dev; `command`, `dialog`, `sheet`, `chart` — командой `npx shadcn@latest add …` (в них `cn` переключён на общий `@/lib/utils`). Графики — на Recharts 3; G16 написан под Recharts 2, поправлены только типы (описано в начале файла). Цвета графиков — `--chart-1…5` в `src/index.css`.
