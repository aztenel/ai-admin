# Новый пульт чатов (фаза 4 `REFACTORING.md`)

React 19 + TypeScript + Vite + Tailwind CSS v4. Рабочий пульт по-прежнему `pult/` → `pult.gen.js`; эта папка на него и на бота не влияет и **на сайт не выкладывается**.

## Что проверено

| Что | Как проверено |
|---|---|
| Вход, список чатов обоих номеров, переписка, ответ, «Взять чат», «Вернуть бота», «Готово», заявки, сведения о номерах, рассылки | **На заглушках, но настоящим кодом бота**: `npm run dev:live` — `test/devserver.mjs` (KV в памяти, заглушки Meta, Green-API, Telegram, «ИИ») + этот пульт; браузер Playwright |
| Вид на 375×812, 390×844, 402×874, 430×932, 768×1024, 1024×768, 1280×800, 1440×900, 1728×1117, светлая и тёмная тема; на телефонах — с изображённым вырезом экрана и открытой клавиатурой; телефон горизонтально; крупный шрифт | Снимки Playwright (`npm run shots`), без горизонтальной прокрутки и ошибок в консоли |
| Тема «как в системе / светлая / тёмная»: сохраняется после перезагрузки, следует системе | Playwright |
| **Не проверено вживую**: настоящий iPhone (клавиатура, вырезы экрана, жест «назад»), настоящие номера Meta и Green-API, программа для Windows | — |

## Запуск

```bash
cd apps/pult && npm install
npm run dev        # демо-данные, без сервера: http://localhost:5173/
npm run dev:live   # настоящий код бота на заглушках: http://127.0.0.1:5174/app/?c=dent (ключ owner-key-123456)
npm run build      # проверка типов + сборка в dist/ (в git не попадает)
npm run shots -- <папка>   # снимки всех размеров (при запущенном npm run dev)
```

## Откуда данные

- **Рабочий режим** (по умолчанию): тот же API, что у рабочего пульта, — `/api/inbox/me|list|chat|send|act|media|leads`, `/api/bc/list` (телефоны и состояние номеров, рассылки), `/api/studio/list` (компании владельца). Права и арендатора проверяет сервер; параметр `c=` — только выбор среди разрешённых. Сервер не ответил — пульт пишет, что случилось; демо вместо настоящих данных не подставляется.
- **Демо** — только явно: сборка с `VITE_PULT_DATA=demo`, адрес `/demo…` или `?demo`. Три вымышленные компании (`src/data/demo.ts`): барбершоп с двумя номерами, сервис-центр с двумя филиалами, новая компания без чатов. Пометка «демо» рядом с названием, звонки не набираются. В рабочем режиме файл демо не загружается.

## Как устроено

- `src/model/` — понятия: компания → (филиалы) → каналы (номера) → чаты → сообщения. Канал (через какой номер) и режим (бот, человек, просьба) — разные вещи.
- `src/data/live.ts` — перевод ответов сервера в эти понятия; `demo.ts` — демо с тем же интерфейсом; `read-marks.ts` — «прочитано» на этом устройстве.
- `src/state/store.ts` — состояние, опрос раз в 15 с (свёрнутая вкладка не опрашивает), мгновенная отправка с «Повторить» при ошибке.
- `src/inbox/` — чаты: список, выбор номера/филиала, переписка, просьбы клиента, поле ответа, карточка клиента.
- `src/screens/` — заявки, рассылки, настройки (грузятся при первом открытии).
- `src/shell/` — полоса разделов (планшет, компьютер), вкладки снизу (телефон), компания.
- `src/index.css` — цвета и шрифт. Палитра Tailwind по умолчанию отключена: в компонентах только токены (`bg-surface`, `text-fg-2`…).

**Раскладка.** Телефон (< 768): список → переписка → карточка клиента, по одному экрану, «назад» — жестом или кнопкой; список не выгружается, прокрутка сохраняется. Планшет и ноутбук (768–1279): список + переписка, карточка выезжает справа. Компьютер (≥ 1280): три колонки, карточку можно скрыть — выбор запоминается.

**iPhone.** `viewport-fit=cover`, отступы `env(safe-area-inset-*)`, высота `100dvh`; при открытой клавиатуре корень пульта повторяет `visualViewport` (тот же приём, что в рабочем пульте), поле ответа остаётся над клавиатурой. Поля ввода — 16 px (без увеличения страницы), кнопки — от 44 px. Размер шрифта следует «Размеру текста» iOS.

**Вид** — арт-дирекция «тихий инструмент» (третий проход 18.10.2026; синий вместо шафрана — решение владельца того же дня). Холодная нейтральная основа и три ступени поверхностей: полотно `#F2F4F7`, белые панели, заливка `#EEF1F5`. Текст `#11161D` / `#4A5363` / `#616A7A`. Иерархию строят размер, вес и отступы, а не цвет. Синий `#1D5FD0` — одна насыщенная роль (главное действие, отправка, сообщения человека, фокус) и одна бледная (выбранное). Красный — только ошибка, необратимое действие и клиент, который ждёт человека; зелёный — подключено, выполнено. Тёмная тема — графит (`#16191E`, `#0F1114`) и синий `#2F6BE0`, не чёрная. Контраст текста проверен расчётом: подписи ≥ 4.5:1 на всех фонах обеих тем. Палитра и шкала шрифта — `src/index.css`.

- **Список.** Название компании — крупный заголовок; справа капсула «Все номера» (выбран один номер — капсула синяя). В демо над названием строка «Демо · данные вымышленные». Фильтры — вкладки с синей чертой; число ждущих — красное. Строка чата всегда в три строки одной высоты: кто и когда; последнее сообщение; одной фразой — кто ведёт и через какой номер («Просит человека · ИИ-администратор», «Человек · Основной WhatsApp»; обычное «ведёт бот» — только значком). Клиент ждёт — вместо времени сообщения красным «сколько ждёт».
- **Переписка.** В шапке — номер, через который идёт чат; карточку клиента открывает нажатие на имя. Под именем, в самой шапке, — плашка с главным действием: розовая «Просит человека · ждёт 9 мин — Взять чат», серая «Ведёте вы · бот молчит до … — Вернуть бота». На телефоне у «назад» — сколько ещё чатов ждут человека. Просьба клиента — карточкой-задачей над полем ответа. Над полем, по линии текста, мелко: с какого номера уйдёт ответ.
- **Пузыри — три голоса, три веса:** клиент — нейтральный серый, бот — бледно-синий, человек — сплошной синий (это сказали вы). Подпись «Бот» / «Оператор» / «Оператор, с телефона» со значком — только когда отвечающий сменился. Время — мелко внутри пузыря.
- Карточка клиента — подпись над значением, как в «Контактах» iPhone; настройки и заявки — сгруппированные списки на полотне, значки в плитках.
- Скругления по ступеням: 10 px — кнопки, поля и плитки, 12–16 px — плашки, группы и карточки, 18–20 px — пузыри, поле ответа и листы. Значки Lucide 20 px в навигации, 16 px в тексте. Системный шрифт (San Francisco на iPhone и Mac).
- Вырезы экрана — через переменные `--safe-t/-b/-l/-r` (`src/index.css`): так снимки проверки изображают iPhone с вырезом и «полоской Домой».

## Два номера одной компании

- У компании может быть номер Meta Cloud API (`wa`) и номер Green-API (`ga`), плюс чат на сайте. Справа от названия компании — выбор: «Все номера» или один номер (с филиалами — «Все филиалы» → филиал → номер). Число ждущих ответа — у каждого пункта.
- В строке чата — номер, на который написал клиент; над полем ответа — «С номера …». Сервер отвечает с того же номера (`/api/inbox/send` по `ch` чата).
- Клиент, писавший на оба номера, — две переписки одного контакта (контакт — по номеру телефона). В карточке клиента — «Писал и на другой номер» с переходом. Переписки не сливаются и не переносятся между номерами.
- Телефон и состояние номеров — из `/api/bc/list` (Meta: `display_phone_number`, Green-API: `wid`).

## Чего нет на сервере (и что нужно сделать)

1. **Названия номеров** («ИИ-администратор», «Основной WhatsApp»). Сейчас показываем телефон и вид подключения. Наименьший путь: два поля паспорта (`waLabel`, `gaLabel`) в `/studio` + поле `channels` в ответе `/api/inbox/list` (`[{ ch, name, phone }]`); после фазы 2 — колонка `channels.label`.
2. **Бот только на одном номере.** Сейчас бот отвечает на обоих номерах (пока человек не ответил — тогда пауза 2 ч). Если основной номер должен быть «только люди», нужна настройка на канал и проверка в `handleGreen`/`handleWAText` до вызова бота — это правка логики бота, нужна отдельная задача и тесты.
3. **Филиалы** — в сервере их нет (одна локация Altegio на компанию). Пульт показывает выбор филиала, только если сервер вернёт филиалы; сейчас — только в демо.
4. **Непрочитанные** — счётчика на сервере нет (цель — `chats.unread_count`). Пока «новое» = сообщение клиента после последнего открытия чата **на этом устройстве**.
5. **Назначенный оператор**, статусы доставки, отправка файлов, фото профиля — в API нет; в пульте не показываются.
6. **Раздача с сайта**: собранный пульт нужно положить в `public/app/` и раздавать Worker (Workers Static Assets, фаза 3–4) — выкладка только по слову владельца.

## Решения

- Стек не меняли: React 19 + Vite + Tailwind 4 не мешают ни PWA на iPhone, ни Tauri, ни будущему Capacitor; адреса внутри пульта — после `#`, сборка с `base: "./"` открывается с любого пути.
- Убраны: доска «канбан», графики выручки (Recharts), «Записи» и «Клиенты» на вымышленных цифрах (на сервере для них нет данных), анимации `motion`, библиотека значков Tabler, шрифт Inter, компоненты 21st.dev. JS при первом открытии — 139 КБ gzip (было 175, бюджет 150).
