# Сайт winchester.kz

Исходник сайта барбершопа Winchester. Загружает на hoster.kz (`httpdocs`, панель Plesk) сам владелец: сессия отдаёт ему zip и
список файлов. 24.10.2026 сюда снята копия живого сайта, в тот же день сделана новая версия: без приёмов «ИИ-дизайна»,
со стоковыми фото и казахской страницей (`docs/winchester-site-task.md`). `aztenel/landing` отстал — оттуда не брать.

| Файл | Что это |
|---|---|
| `src/page.html` | **Шаблон** обеих страниц: разметка, весь CSS и JS. `{{ключ}}` — текст из словаря |
| `src/ru.mjs`, `src/kk.mjs` | **Словари**: русский (на «ты», как форма записи) и казахский (на «Сіз»; перевод нужно проверить носителю языка) |
| `src/sprite.svg` | Значки страницы. `#emblem`, `#cal`, `#wa` берёт и форма записи — не переименовывать |
| `build.mjs` | Сборка: шаблон + словарь → `index.html` и `kk/index.html` |
| `index.html`, `kk/index.html` | **Готовые страницы** (собраны `build.mjs`, руками не править) |
| `privacy.html` | Политика конфиденциальности (одна, на русском; казахская страница ссылается на неё) |
| `logo.svg`, `favicon.svg`, `og-image.jpg` | Логотип клиента, значок вкладки, превью ссылки 1200×630 |
| `assets/fonts/*.woff2` | Oswald 600, Rye 400, Manrope (переменный) — локально, без Google Fonts; для казахских букв — ниже |
| `assets/photos/*.jpg` | Кадры из видео Winchester без людей и стоковые фото (ниже). Фото с людьми здесь **нет** |
| `robots.txt`, `sitemap.xml` | Для поисковиков; в `sitemap.xml` — обе страницы со ссылками друг на друга |
| `audit.cjs` | Замер по правилам ui-ux-pro-max: контраст, размер кнопок, мелкий текст, горизонтальная прокрутка |

**Нет в этой папке, но лежит на сайте:** `assets/booking.js`, `assets/booking.css` — форма записи (исходник — `apps/site-booking/`,
при сборке zip копировать оттуда); `assets/photos/master-aidos.jpg`, `master-aidyn.jpg`, `master-alisher.jpg` — фото мастеров из
Altegio (живые люди, репозиторий публичный — только в zip). Фото мастера нет — на сайте первая буква имени, как в форме.
`assets/photos/hero*.jpg` на сайте — кадр зала с мастерами и клиентами (из видео, тоже только в zip); в репозитории под теми же
именами лежит кадр полок без людей — чтобы страница из репозитория не была без первого фото.
Появятся фото Тони и Руслана — положить на сайт `master-toni.jpg`, `master-ruslan.jpg` (квадрат, от 220×220): страница их уже ждёт.

## Как править

1. Текст — в `src/ru.mjs` и тот же ключ в `src/kk.mjs`; вёрстка и стили — в `src/page.html`.
2. `node apps/winchester-site/build.mjs` — пересобрать обе страницы (ключ есть в одном словаре и нет в другом — ошибка).
3. `node apps/winchester-site/build.mjs --check` — готовые страницы совпадают с исходниками.

Правила вида (что убрано и почему — `docs/winchester-site-task.md` §4): заглавными — только заголовки разделов (Oswald, как
надпись на кольце логотипа), без надписей-«бровей» над разделами, нумерации «01 ·», строк через «·», выделенных слов в заголовках
и «выплывания» блоков при прокрутке. Rye — только название комплекса «Premium». Палитру и имена CSS-переменных не менять:
их читает форма записи (`--obsidian`, `--walnut`, `--burgundy`, `--ivory`, `--brass`, `--taupe`, `--serif`, `--sans`, `--rye`).
Кнопки записи — `data-book` + рабочий `href` на WhatsApp + `data-wa` (без JS и при сбое формы ведут в WhatsApp).

## Движение (25.10.2026, выбор владельца после разбора motion.dev, animejs.com, 21st.dev)

Без библиотек (Motion и Anime.js весят 40–55 КБ сжатыми — больше всей страницы; блоки 21st.dev — React и в основном тот самый
«ИИ-вид»), только CSS и свой JS в `src/page.html`:
- **первый экран при открытии** — фото медленно приближается, строки заголовка выезжают по очереди (строки считаются по
  переносам на этом экране после загрузки шрифта, через 2,4 с заголовок снова обычный текст), за ними текст, кнопки, телефон.
  Класс `intro` ставит скрипт в `<head>` до отрисовки; без JS и при «уменьшить движение» его нет — всё сразу на месте;
  скрипт сломался — через 2,5 с всё видно (`introSafe`);
- **цены «Барберы / Шеф-барбер Тони»** — меняющаяся цена уходит вверх, новая приходит снизу, одинаковые стоят на месте
  (WAAPI, `flip`); на телефоне фото групп стоят под ценами, чтобы переключатель и цены были на одном экране.
Других движений нет (блоки при прокрутке не «выплывают» — §4 задания).

## Шрифты для казахского

В Oswald казахские буквы есть в подмножестве `cyrillic-ext` (`oswald-cyrillic-ext-600-normal.woff2`, @fontsource/oswald 5.3.0, OFL).
В **Manrope их нет совсем** — ни в одном подмножестве нет ә ғ қ ң ұ (проверено 24.10.2026 по таблицам символов), есть только
ө ү һ (`manrope-cyrillic-ext-wght-normal.woff2`, @fontsource-variable/manrope 5.3.0). Пять недостающих пар букв берутся из Inter
(похожий гротеск, OFL; `inter-kazakh-*.woff2` — вырезаны из @fontsource-variable/inter 5.3.0 только эти буквы, ≈ 4 КБ) под тем же
именем `Manrope` через `unicode-range`. Rye — только латиница, на казахском тексте не используется. Русская страница эти файлы
не грузит (браузер берёт шрифт только под буквы, которые есть на странице), кроме ссылки «Қазақша».

## Проверить у себя

- `node apps/winchester-site/build.mjs --check` — страницы собраны из исходников.
- `node test/site-booking-e2e.mjs <папка для снимков> apps/winchester-site` — страница + форма записи на заглушках (скрипт сам берёт
  `booking.js`/`booking.css` из `apps/site-booking` и подменяет `data-api`), с разделом 13 — казахская страница.
- `node apps/winchester-site/audit.cjs apps/winchester-site [/kk/]` — замер по правилам ui-ux-pro-max (телефон 390 px, компьютер 1440 px).

Ничего не обещать как «на сайте уже есть», пока владелец не сказал, что загрузил, и это не видно по https://winchester.kz.
