# Онлайн-запись на сайте (winchester.kz)

Своя форма записи вместо виджета Altegio: окно поверх страницы сайта, шаги **мастер → услуги → день и время → контакты → готово**.
Данные берёт у Worker ai-admin: `/api/site/<клиент>/{catalog,nearest,dates,times,book}` (сервер — `src/controllers/site.js`,
`src/services/sitebook/`, режимы и пределы — CLAUDE.md §2.2 «Запись с сайта winchester.kz»).

| Файл | Что это |
|---|---|
| `booking.js` | Скрипт формы: ES5 без библиотек, как скрипт самого сайта (≈ 50 КБ, gzip ≈ 18 КБ) |
| `booking.css` | Стили формы, все правила внутри `.wbk` (≈ 16 КБ, gzip ≈ 4,7 КБ) |
| `demo/index.html` | Небольшая страница с токенами и классами сайта — по ней по умолчанию идёт e2e |

Готовые к загрузке файлы сайта (правленые копии живых `index.html` и `privacy.html` + эти два файла в `assets/`) лежат вне
репозитория — у владельца; ниже — что в них поменять, если правите заново.

## Как подключить на сайте

1. В `<head>`: `<link rel="preconnect" href="https://ai-admin.azikonps4.workers.dev" crossorigin>`.
2. Перед `</body>`, **после** встроенного скрипта сайта:
   `<script src="assets/booking.js" data-api="https://ai-admin.azikonps4.workers.dev" data-client="winchester" defer></script>`.
   Стили скрипт подключит сам (`booking.css` рядом с ним).
3. Кнопкам записи добавить атрибут `data-book`. `href` на WhatsApp и `data-wa` **оставить**: без JS, при выключенной онлайн-записи
   и при сбое API кнопка по-прежнему ведёт в WhatsApp.
4. В SVG-спрайт сайта — значок календаря `<symbol id="cal">` (контур, `currentColor`); значки `#wa` и `#emblem` форма берёт из спрайта.
5. `privacy.html` выкладывать **вместе** с формой: в ней раздел о форме, согласии и сроках хранения (через сайт идёт проверка Meta).

Атрибуты скрипта: `data-api` (адрес Worker), `data-client` (id клиента, по умолчанию `winchester`), `data-css` (адрес стилей),
`data-map` (ссылка «Как добраться», по умолчанию 2ГИС Winchester), `data-privacy` (по умолчанию `privacy.html`).

### Значения `data-book`

| Значение | Что откроется |
|---|---|
| пусто | Шаг «Мастер», ничего не выбрано; если в этой вкладке уже выбирали — шаг, на котором остановились, с прежним выбором |
| `m:<имя>` | Сразу шаг «Услуги» у мастера: `m:тони`, `m:айдос`, `m:айдын`, `m:алишер`, `m:руслан` (начало имени, ё = е) |
| `s:<ключ>` | Шаг «Мастер» с выбранной услугой, у каждого мастера — её цена: `s:premium`, `s:отец-и-сын`, `s:мужская-стрижка` … |

Ключ услуги — название строчными, без скобок, кавычек и слова «комплекс», через дефис (`svKey` на сервере).
Ссылка извне: `https://winchester.kz/#book`, `#book=m:тони`, `#book=s:premium` — окно откроется после загрузки каталога.

## Как устроено

- **Когда перехватывается клик.** После загрузки страницы, в простое, скрипт спрашивает каталог и заранее собирает окно (скрыто) —
  нажатие только показывает его (кнопка с услугой, например «Записаться на Premium», — шаг рисуется заново под неё). Каталог ещё
  грузится — окно со скелетоном. Ответ `503 off` или ошибка ранней загрузки, нет стилей формы или нет `fetch` — клик не перехватывается,
  ссылка ведёт в WhatsApp. После ошибки форма сама спрашивает каталог снова: через 4 с, 15 с, минуту, при появлении сети и при нажатии
  на кнопку записи — следующее нажатие уже откроет форму. Ctrl/Cmd/Shift/средняя кнопка — не перехватываются. Второе касание
  двойного нажатия (то же место, до 350 мс) в окне не срабатывает: раньше оно выбирало мастера или закрывало окно.
- **Мастер.** «Любой мастер» и мастера из Altegio; у каждого — цена основной услуги (или выбранных), рейтинг, ближайшее свободное
  время (`nearest`). Фото — то же, что на странице сайта (`.ph` с `aria-label` «Тони, …»), когда оно там появится; пока — рамка с буквой.
- **Услуги.** Группы и названия — из настроек сайта на сервере, цены и длительность — у выбранного мастера (у «любого» — «от …»).
  Сменили мастера — выбранные услуги переносятся по ключу, чего он не делает — убирается с подсказкой. Не больше 5 услуг.
- **Время.** Лента дней (выходные мастера — бледные), время группами «Утро / День / Вечер» — только начала, где мастер свободен
  на всю длительность услуг. У «любого мастера» у каждого времени подписан назначенный мастер.
- **Контакты.** Итог с «Изменить» у каждой части (после правки «Дальше» возвращает к проверке), имя, телефон с маской
  `+7 7XX XXX XX XX` (принимает «8…», «7…», вставку), комментарий до 150 знаков, скрытое поле-ловушка для роботов.
  В режиме проверки (`dry`) — кнопка «Отправить заявку» и пояснение, что запись внесёт администратор.
- **Ответы сервера.** «Время только что заняли» — назад к выбору времени со свежим списком; `too_fast`, `expired`, `in_progress` —
  форма сама повторяет с тем же `rid`; пределы и прочие отказы — текст сервера и кнопки «Позвонить» / «Написать в WhatsApp»;
  `unknown` — отдельный экран «Не получили подтверждения» без кнопки повтора (так же — если сервер всё ещё записывает после пяти
  повторов `in_progress`); `refused` (Altegio отказал, заявка у администратора) — экран «Заявка у администратора».
- **Во время отправки** (до 30 с: сервер отвечает не дольше) окно не закрывается и шаг не меняется — ни крестиком, ни Esc, ни «назад»
  (в окне и браузера): подсказка «Заявка отправляется…». Иначе ответ терялся, и клиент мог записаться второй раз. Кнопка отправки —
  `aria-disabled` (фокус остаётся на ней), после 8 с — «Расписание отвечает дольше обычного».
- **Ближайший день.** У пустого дня кнопка ведёт на ближайший день, где у мастера есть свободное время (сервер смотрит до 4 рабочих
  дней вперёд), а не просто на следующий рабочий.
- **Готово.** Настоящая запись — «Ждём тебя в Winchester», файл `.ics` для календаря, «Как добраться». Проверка — «Заявка принята».
- **Выбор** (мастер, услуги, день, время) хранится в `sessionStorage` до закрытия вкладки; имя и телефон — только в памяти.
- **Доступность.** `role=dialog`, фокус не выходит из окна, Esc (где бы ни был фокус) и «назад» браузера закрывают окно (или шаг
  назад), фокус возвращается на кнопку, а если она скрыта (меню на телефоне закрылось) — на кнопку этого меню (`aria-controls`);
  итог и ошибки объявляются (`aria-live`), лента дней — стрелками.
- **Анимации** — только `transform` и `opacity`, кривая сайта; при «уменьшить движение» их нет. Уходящий шаг — только `wbk-lv`
  (классы появления с него снимаются, иначе он въезжал поверх нового). Тяжёлое — не в момент нажатия: окно собрано заранее, фокус
  и прокрутка — в следующем кадре, услуги — первая группа сразу, остальные по одной за кадр.
- **Вид.** Токены, шрифты и классы сайта (`.btn`, `.label`, `.tlink`, `.ph`), углы прямые; телефон и планшет (≤ 860 px) — лист на весь
  экран снизу, компьютер — панель справа, от 1100 px — с карточкой «Твоя запись».

## Проверка

```
npm run e2e:site                                   # демо-страница, снимки в /tmp/site-e2e
SITE_ASSETS=<папка со шрифтами и logo.svg сайта> node test/site-booking-e2e.mjs <папка снимков> <папка с правленой копией сайта>
```

`test/site-booking-e2e.mjs` поднимает `test/devserver.mjs` (Altegio — заглушка Winchester `test/fixtures/winchester-altegio.mjs`),
свой статический сервер для страницы и пропуск с отдельным «адресом посетителя» на каждый сценарий; всё, что идёт не на 127.0.0.1,
обрывается и записывается — в конце список должен быть пуст. Playwright: `PLAYWRIGHT_PATH` или `/opt/node-tools/…/playwright/index.mjs`,
браузер — `PW_CHROMIUM` или `/opt/pw-browsers/chromium`. Сценарии: телефон и режим проверки; компьютер и настоящая запись (+ `.ics`);
«любой мастер»; время заняли; нет сети; онлайн-запись выключена; клавиатура; «уменьшить движение»; горизонтальная прокрутка на 320,
390, 820 и 1440 px на каждом шаге; долгие задачи при процессоре ×4; навигация (`#book=…`, «назад», 5 услуг, смена мастера, «Изменить»,
выбор после перезагрузки); отказы сервера, «Не получили подтверждения» и «Заявка у администратора»; находки проверки 21.10.2026
(«назад», Esc и крестик во время отправки, уходящий шаг, первая кнопка «Premium», двойное нажатие, повтор каталога, «Ближайший день»,
пустое имя, рамка поля с ошибкой, «Готово» по центру, фокус после меню); снимки каждого шага (390, 360, 820, 1280, 1920 px).

Проверено на заглушках. **Вживую не проверено:** настоящий Altegio (`book_services?staff_id`, сетка без услуг), CORS с winchester.kz,
Safari на iPhone и Android-браузеры.
