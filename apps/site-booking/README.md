# Онлайн-запись на сайте (winchester.kz)

Своя форма записи вместо виджета Altegio: окно поверх страницы сайта, путь — **как онлайн-запись Altegio** (решение владельца
22.10.2026), вид — сайта: **мастер** (фото, должность, звёзды и отзывы, «Любой специалист») → **услуги** (категории, мультивыбор,
«ещё») → **календарь месяца и время** → **детали записи** (у каждого блока «изменить») и **данные** (имя, телефон, комментарий,
напоминание, согласие) → **«Вы записаны»**. Данные берёт только у Worker ai-admin: `/api/site/<клиент>/{catalog,nearest,dates,times,book}`
и `/photo/<мастер>` (сервер — `src/controllers/site.js`, `src/services/sitebook/`, режимы и пределы — CLAUDE.md §2.2 «Запись с сайта
winchester.kz»). Ключи Altegio — только на сервере; форма к Altegio не обращается.

| Файл | Что это |
|---|---|
| `booking.js` | Скрипт формы: ES5 без библиотек, как скрипт самого сайта (≈ 75 КБ, gzip ≈ 26 КБ) |
| `booking.css` | Стили формы, все правила внутри `.wbk` (≈ 23 КБ, gzip ≈ 6,4 КБ) |
| `demo/index.html` | Небольшая страница с токенами и классами сайта — по ней по умолчанию идёт e2e |

Готовые к загрузке файлы сайта (правленые копии живых `index.html` и `privacy.html` + эти два файла в `assets/`) лежат вне
репозитория — у владельца; ниже — что в них поменять, если правите заново.

## Как подключить на сайте

1. В `<head>`: `<link rel="preconnect" href="https://ai-admin.azikonps4.workers.dev" crossorigin>`.
2. Перед `</body>`, **после** встроенного скрипта сайта:
   `<script src="assets/booking.js" data-api="https://ai-admin.azikonps4.workers.dev" data-client="winchester" defer></script>`.
   Стили скрипт подключит сам (`booking.css` рядом с ним).
3. Кнопкам записи добавить атрибут `data-book`. `href` на WhatsApp и `data-wa` **оставить**: без JS, при выключенной онлайн-записи
   и при сбое API кнопка по-прежнему ведёт в WhatsApp.
4. В SVG-спрайт сайта — значок календаря `<symbol id="cal">` (контур, `currentColor`); значки `#wa` и `#emblem` форма берёт из спрайта.
5. `privacy.html` выкладывать **вместе** с формой: в ней раздел о форме, согласии и сроках хранения (через сайт идёт проверка Meta).

Атрибуты скрипта: `data-api` (адрес Worker), `data-client` (id клиента, по умолчанию `winchester`), `data-css` (адрес стилей),
`data-map` (ссылка «Как добраться», по умолчанию 2ГИС Winchester), `data-privacy` (по умолчанию `privacy.html`).

### Значения `data-book`

| Значение | Что откроется |
|---|---|
| пусто | Шаг «Мастер», ничего не выбрано; если в этой вкладке уже выбирали — шаг, на котором остановились, с прежним выбором |
| `m:<имя>` | Сразу шаг «Услуги» у мастера: `m:тони`, `m:айдос`, `m:айдын`, `m:алишер`, `m:руслан` (начало имени, ё = е) |
| `s:<ключ>` | Шаг «Мастер» с выбранной услугой, у каждого мастера — её цена: `s:premium`, `s:отец-и-сын`, `s:мужская-стрижка` … |

Ключ услуги — название строчными, без скобок, кавычек и слова «комплекс», через дефис (`svKey` на сервере).
Ссылка извне: `https://winchester.kz/#book`, `#book=m:тони`, `#book=s:premium` — окно откроется после загрузки каталога.

## Как устроено

- **Когда перехватывается клик.** После загрузки страницы, в простое, скрипт спрашивает каталог и заранее собирает окно (скрыто) —
  нажатие только показывает его (кнопка с услугой, например «Записаться на Premium», — шаг рисуется заново под неё). Каталог ещё
  грузится — окно со скелетоном. Ответ `503 off` или ошибка ранней загрузки, нет стилей формы или нет `fetch` — клик не перехватывается,
  ссылка ведёт в WhatsApp. После ошибки форма сама спрашивает каталог снова: через 4 с, 15 с, минуту, при появлении сети и при нажатии
  на кнопку записи — следующее нажатие уже откроет форму. Ctrl/Cmd/Shift/средняя кнопка — не перехватываются. Второе касание
  двойного нажатия (то же место, до 350 мс) в окне не срабатывает: раньше оно выбирало мастера или закрывало окно.
- **Мастер** (как в Altegio). «Любой специалист» первым, дальше мастера из Altegio: фото кругом (`catalog.staff[].photo` —
  адрес нашего Worker `/api/site/<клиент>/photo/<id>?v=…`, `has_photo`; `loading=lazy`, `decoding=async`, размер круга задан в CSS —
  фото приходит позже и ничего не сдвигает; нет фото или не загрузилось — буква имени), должность, пять звёзд по оценке и число
  отзывов (если Altegio их показывает), цена основной услуги (или выбранных) и ближайшее свободное время (`nearest`).
- **Услуги.** Категории — чипы сверху (липкие при прокрутке, щелчок — группа встаёт под чипы; последняя группа тоже: снизу
  добавляется место, как в Altegio), группы и названия — из настроек сайта на сервере, цены и длительность — у выбранного мастера
  (у «любого» — «от …»). Длинное описание (Premium) — в одну строку с «ещё». Вся строка — подпись флажка. Сменили мастера — выбранные
  услуги переносятся по ключу, чего он не делает — убирается с подсказкой. Не больше 5 услуг. На узком телефоне (< 380 px) цена —
  строкой ниже, как в Altegio.
- **Календарь месяца.** Сетка Пн–Вс, название месяца, стрелки листания — пока разрешает Altegio (горизонт — `to` из ответа `dates`,
  а до ответа — из `nearest`, потом — потолок каталога); доступные дни яркие, выходные мастера, прошлые дни и дни за горизонтом —
  бледные и не нажимаются; сегодня — точка; выбранный — заливка `--brass`; под календарём — «Запись открыта до …». День, где время
  кончилось (узнали из ответа `times`: сам день, дни до первого свободного и до «ближайшего дня»), бледнеет с подписью «всё занято».
  Дни спрашиваются по месяцам (`dates?…&month=ГГГГ-ММ`; ответ без `month` форма режет по месяцам сама), а открытые дни каждого мастера
  на весь горизонт уже есть в `nearest` — календарь рисуется сразу. Клавиатура: `role=grid`, в порядке Tab — один день, стрелки — день
  и неделя, Home/End — начало и конец недели, PageUp/PageDown — месяц; у каждого дня `aria-label` с полной датой.
- **Время** — группами «Утро / День / Вечер», только начала, где мастер свободен на всю длительность услуг. У «любого специалиста» у
  каждого времени подписан назначенный мастер. Время — одна остановка Tab (выбранное или первое), дальше стрелками: ← → — соседнее,
  ↑ ↓ — тот же столбец ряда выше или ниже, Home/End — первое и последнее; Enter или пробел выбирает. На низком телефоне (360×740,
  375×667) касание дня плавно прокручивает окно к времени этого дня, если первый ряд времени не виден (проверка 22.10.2026: календарь
  занимал весь экран, и касание «ничего не меняло»); с клавиатуры окно не двигается.
- **Время под мастером** (шаг 1, «Ближайшее») — тоже выбор: касание времени выбирает мастера, а день и время — пожелание: на шаге времени
  они выбраны, если выбранные услуги помещаются (иначе — подсказка «это уже не помещается»).
- **Мгновенно.** Каталог — после загрузки страницы, в простое (`requestIdleCallback`), окно собирается заранее. Наведение, касание или
  фокус на кнопке записи — `nearest` (ближайшее время и дни всех мастеров). Выбраны мастер и услуги — сразу дни текущего и следующего
  месяца и время первого свободного дня (к шагу времени всё уже есть). Выбран день — время соседнего открытого дня заранее; наведение
  (или фокус) на день дольше 0,18 с — его время, но не больше 6 дней в минуту (проверка 22.10.2026: мышью по месяцу при «любом
  специалисте» — 63 запроса к Altegio за 11 с, а его предел 5 запросов в секунду общий с ботом). Ответы — в памяти (время — минута, дни — 4 минуты), одинаковый запрос в пути — общий; заранее — не
  больше двух запросов времени одновременно. Ждём — прежнее время тускнеет, скелетон — только если ответ дольше 0,2 с.
- **Детали записи** (как в Altegio): мастер (фото, должность), дата и время «Суббота, 3 октября, 15:00 — 16:15», услуги с
  длительностью и ценой, «Итого»; у мастера, времени и услуг — «изменить» (карандаш): возврат на свой шаг без потери остального —
  день и время остаются пожеланием и выбираются снова, если ещё помещаются (иначе — подсказка), имя, телефон и напоминание на месте;
  «Дальше» возвращает к деталям — после «изменить» услуги или мастера сразу, если прежнее время ещё помещается и ответ о нём уже есть
  (иначе — через шаг времени, где оно выбрано). Время «чч:мм — чч:мм» — одной строкой (неразрывные пробелы). На компьютере (от 1100 px) — две колонки: детали слева, данные справа.
- **Данные.** Имя\*, телефон\* с маской `+7 7XX XXX XX XX` (принимает «8…», «7…», вставку), комментарий до 150 знаков, напоминание
  (не напоминать / за 1, 2, 3 часа / за день; по умолчанию — `catalog.notify.def`, за 1 час; варианты, которых нет у сервера, не
  показываются) → `notify` в заявке (сервер передаёт в Altegio `notify_by_sms`), галочка «Я даю согласие на обработку персональных
  данных и подтверждаю ознакомление с Политикой конфиденциальности» (ссылка на `privacy.html`) → `consent: true`. Без галочки кнопка
  `aria-disabled` с подсказкой; нажали — заявка не уходит, фокус на галочке. Скрытое поле-ловушка для роботов. В режиме проверки
  (`dry`) — кнопка «Отправить заявку» и пояснение «Время свободно. Запись в журнал мастера внесёт администратор…» — без слова
  «проверка»: посетитель читал его как «не по-настоящему» (проверка 22.10.2026).
- **Ответы сервера.** «Время только что заняли» — назад к выбору времени со свежим списком; `too_fast`, `expired`, `in_progress` —
  форма сама повторяет с тем же `rid`; пределы и прочие отказы — текст сервера и кнопки «Позвонить» / «Написать в WhatsApp»;
  `unknown` — отдельный экран «Не получили подтверждения» без кнопки повтора (так же — если сервер всё ещё записывает после пяти
  повторов `in_progress`); `refused` (Altegio отказал, заявка у администратора) — экран «Заявка у администратора».
- **Во время отправки** (до 30 с: сервер отвечает не дольше) окно не закрывается и шаг не меняется — ни крестиком, ни Esc, ни «назад»
  (в окне и браузера): подсказка «Заявка отправляется…». Иначе ответ терялся, и клиент мог записаться второй раз. Кнопка отправки —
  `aria-disabled` (фокус остаётся на ней), после 8 с — «Расписание отвечает дольше обычного».
- **Ближайший день.** У пустого дня кнопка ведёт на ближайший день, где у мастера есть свободное время (сервер смотрит до 4 рабочих
  дней вперёд), а не просто на следующий рабочий.
- **Готово.** Настоящая запись — значок-галочка, «Вы записаны», детали, файл `.ics` для календаря, «Как добраться». Режим `dry` —
  «Заявка принята» и честный текст: время свободно, заявка у администратора, он внесёт запись в журнал мастера и подтвердит.
- **Выбор** (мастер, услуги, день, время) хранится в `sessionStorage` до закрытия вкладки; имя, телефон и согласие — только в памяти.
- **Доступность.** `role=dialog`, фокус не выходит из окна, Esc (где бы ни был фокус) и «назад» браузера закрывают окно (или шаг
  назад), фокус возвращается на кнопку, а если она скрыта (меню на телефоне закрылось) — на кнопку этого меню (`aria-controls`);
  итог и ошибки объявляются (`aria-live`), календарь — стрелками (см. выше), название месяца объявляется при листании.
- **Анимации** — только `transform` и `opacity`, кривая сайта; при «уменьшить движение» их нет. Прежний шаг убирается сразу, новый
  въезжает (`wbk-en`): уходящий шаг с анимацией держал в кадре оба шага, и переход «мастер → услуги» (фото, тени) длился 55–100 мс
  при процессоре ×4 (проверка 22.10.2026). Тяжёлое — не в момент нажатия: окно собрано заранее, фокус и прокрутка — в следующем кадре,
  услуги — первая группа сразу, остальные по одной за кадр.
- **Вид.** Токены, шрифты и классы сайта (`.btn`, `.label`, `.tlink`), углы прямые (кругом — только фото мастера, как в Altegio);
  телефон и планшет (≤ 860 px) — лист на весь экран снизу, компьютер — панель справа, от 1100 px — с карточкой «Твоя запись».

## Проверка

```
npm run e2e:site                                   # демо-страница, снимки в /tmp/site-e2e
SITE_ASSETS=<папка со шрифтами и logo.svg сайта> node test/site-booking-e2e.mjs <папка снимков> <папка с правленой копией сайта>
```

`test/site-booking-e2e.mjs` поднимает `test/devserver.mjs` (Altegio — заглушка Winchester `test/fixtures/winchester-altegio.mjs`),
свой статический сервер для страницы и пропуск с отдельным «адресом посетителя» на каждый сценарий; всё, что идёт не на 127.0.0.1,
обрывается и записывается — в конце список должен быть пуст. Playwright: `PLAYWRIGHT_PATH` или `/opt/node-tools/…/playwright/index.mjs`,
браузер — `PW_CHROMIUM` или `/opt/pw-browsers/chromium`. Сценарии: телефон и режим проверки (детали записи, напоминание, согласие —
без галочки заявка не уходит, с ней `consent: true` и `notify` в запросе); компьютер и настоящая запись (напоминание за день, «Вы
записаны», `.ics`); «любой специалист»; время заняли; нет сети; онлайн-запись выключена; клавиатура (календарь стрелками, PageUp/Down,
согласие пробелом); «уменьшить движение»; горизонтальная прокрутка на 320, 360, 390, 820, 1280 и 1920 px на каждом шаге; долгие задачи
при процессоре ×4 (с листанием месяцев); навигация; отказы сервера; находки проверки 21.10.2026; календарь месяца (360 px: Пн–Вс,
прошлые дни и выходные не нажимаются, листание ровно до горизонта Altegio, `month=` в запросах); мгновенность (дни и время заранее,
шаг времени без ожидания сети, наведение на день); фото (наш адрес, круг без сдвига, ошибка — буква, без фото — без запроса, путь
через Worker); категории и «ещё»; «изменить» без потери выбора; находки проверки 22.10.2026 (низкий телефон — время после касания
дня на экране, время под мастером выбирает, «Ближайший день» в две строки не слипается, время в деталях на 320 px одной строкой,
наведение — не больше 6 дней в минуту, время — одна остановка Tab, «изменить» услуги → сразу к деталям); снимки каждого шага
(320, 360, 390, 820, 1280, 1920 px).

Известное ограничение: полностью занятый день выглядит доступным, пока его не выберут (или пока форма не узнает о нём из соседних
ответов) — тогда он бледнеет с подписью «всё занято», а под ним кнопка «Ближайший день». Виджет Altegio гасит такие дни заранее:
он спрашивает другой API (`booking/search/dates` с мастером и услугами, `is_bookable` по каждому дню). Подключать его — отдельное
решение: формат с ключом разработчика вживую не проверен, и это ещё запросы к пределу Altegio, общему с ботом.

Проверено на заглушках. **Вживую не проверено:** настоящий Altegio (`book_services?staff_id`, сетка без услуг, горизонт `book_dates`,
фото мастеров, отправит ли Altegio SMS-напоминание по `notify_by_sms`), CORS с winchester.kz, Safari на iPhone (липкие категории,
`align-self: last baseline` у цены) и Android-браузеры.
