# CRM продаж Bot Flow

Своя CRM для холодных продаж: лиды вносятся вручную с телефона, система сама оценивает их (A / B / C), ведёт воронку,
напоминает о перезвонах и встречах. Работает как приложение на iPhone (значок на экране «Домой»).
Отдельный Worker `botflow-crm` в Cloudflare: к ai-admin и данным его клиентов отношения не имеет.

## Что внутри

- `public/` — приложение: `index.html`, `app.js`, `app.css` (без библиотек и сборки), `score.js` — правила оценки и этапы
  (общие с сервером), значки, `manifest.webmanifest`, `_headers` (политика безопасности страницы).
- `src/worker.js` — сервер: вход по ключу, лиды, касания, «Сегодня», воронка, выгрузка CSV. Только `/api/*`.
- `migrations/` — схема базы D1.
- `test/` — проверки: `npm test` (сервер и оценка на базе в памяти, Node 22+), `node test/e2e.mjs` (браузер, размер iPhone).

## Как оценивается лид

Три группы признаков (выбор владельца, 18.11.2026), всё вносится руками за минуту из 2ГИС и Instagram:

| Признак | Баллы |
|---|---|
| Отзывы 2ГИС | от 30 — 10, от 100 — 22, от 300 — 35 |
| Рейтинг | 4,7 и выше — +5, ниже 4,0 — −5 |
| Мастера | от 3 — 12, от 5 — 20, от 8 — 25 |
| Филиалы | 2 — +8, 3 и больше — +15 |
| Подписчики Instagram | от 500 — 5, от 2 000 — 10, от 10 000 — 15 |
| Профиль живой | да — +5, нет — −5 |
| Впечатление | сильный — +15, нормальный — +5, слабый — −5 |

A — от 55 баллов, B — от 30, C — меньше. Заполнено меньше трёх признаков из семи — буквы нет («?», мало данных).
Система записи (Altegio, zapis.kz…) в оценку не входит: это отдельная метка. Пороги — в `public/score.js`.

## Запуск (один раз, с компьютера)

1. Cloudflare → Workers & Pages → Create → Import a repository → `aztenel/ai-admin`.
   Имя — **`botflow-crm`** (должно совпасть с `name` в `wrangler.jsonc`), корневая папка — **`apps/crm`**,
   команда сборки — пусто, команда выкладки — `npx wrangler deploy`, ветка — `main`.
2. В настройках этого Worker → Variables and Secrets → добавить **Secret `CRM_KEY`** — ключ входа, не короче 12 знаков
   (лучше 20+ случайных букв и цифр). В репозиторий и в чат ключ не писать.
3. Открыть адрес Worker на iPhone в Safari → «Поделиться» → «На экран Домой».

База D1 `botflow-crm` уже создана, схема применена (18.11.2026). Новые миграции: `npx wrangler d1 migrations apply botflow-crm --remote`.

## Локально

```
node test/devserver.mjs 8799     # http://127.0.0.1:8799, ключ dev-key-123456, база в памяти
npm test                         # сервер и оценка
node test/e2e.mjs                # браузер (нужен запущенный devserver и Playwright)
```

## Безопасность

- Вход — ключ `CRM_KEY`; после входа — cookie на 60 дней (HttpOnly, Secure, SameSite=Lax, подпись HMAC).
  10 неверных попыток с адреса за 15 минут — пауза.
- Изменяющие запросы принимаются только со своей страницы и только JSON.
- Страница без встроенных скриптов и стилей, внешних адресов нет (`_headers`).
- Данные лидов — только в базе D1, в репозитории их нет. Резервная копия — «Воронка» → «Скачать все лиды (CSV)».
